# The docs moved

The documentation site now lives in its own repository:

**https://github.com/astrodock/astrodock-docs** — published at **https://docs.astrodock.ai**

It was never part of the platform: it is a static site that happens to be hosted on
Astrodock, and keeping it here meant the platform's releases kept bumping its version and
its GitHub Pages workflow kept failing for a reason nobody had acted on.

The marketing site moved for the same reason, to
**https://github.com/astrodock/astrodock-site**.
