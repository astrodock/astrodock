Install on a server

Run on DigitalOcean

The friendliest way to get Astrodock online if you don't already have a server. We'll create a small machine (a "droplet"), point your domain at it, install Docker, and start Astrodock. Plan for about 20–30 minutes the first time.

You'll need

A DigitalOcean account, a domain name (from any registrar), and an SSH key (DigitalOcean will help you add one). Rough cost: a suitable droplet is about $12/month.

  1. Create a droplet

    In DigitalOcean, choose Create → Droplets:

    • Image: pick the Docker image under the Marketplace tab. (That comes with Docker already installed, so you can skip Step 4. If you'd rather use a plain Ubuntu 24.04 LTS image, that's fine too.)
    • Size: a Basic plan with at least 2 GB RAM (1 vCPU). Astrodock builds your apps on the box, and 1 GB can run out of memory during the first build.
    • Authentication: add your SSH key (recommended over a password).

    Create it, and note the droplet's public IP address.

  2. Point your domain at the droplet

    Decide which domain your apps live under. We'll use apps.example.com as the example — every app becomes <name>.apps.example.com, and the dashboard is admin.apps.example.com.

    The easiest route is to let DigitalOcean manage DNS. In DigitalOcean go to Networking → Domains, add your domain, then create one wildcard record:

    Type: A    Hostname: *.apps    Will direct to: <your droplet IP>

    That single record covers the dashboard and every app. (At your registrar, set the domain's nameservers to DigitalOcean's, or skip DO DNS and add the same wildcard A record at your registrar instead.) Full details and other registrars: Custom domains & DNS.

  3. Open the firewall

    Under Networking → Firewalls, create a firewall and attach it to your droplet, allowing inbound SSH (22), HTTP (80), and HTTPS (443). Only those three need to be open.

  4. Connect to the droplet

    ssh root@<your droplet IP>

  5. Install Docker

    Skip this if you used the Docker Marketplace image. On a plain Ubuntu droplet:

    curl -fsSL https://get.docker.com | sh

    Confirm it's ready:

    docker compose version

  6. Get Astrodock

    git clone https://github.com/your-org/astrodock.git
cd astrodock

    (If git is missing: apt-get update && apt-get install -y git.)

  7. Configure — one command

    Run the setup script. It writes your config and generates every secret for you, asking only for your domain, email, and an admin password:

    ./scripts/setup.sh

    Or pass them as flags to skip the questions:

    ./scripts/setup.sh --domain apps.example.com --email you@example.com

    It sets HTTPS to automatic, fills in the five secret keys, writes a locked-down .env, and prints your dashboard URL and admin login. If it auto-generates the admin password, copy it from the output.

    Prefer to edit it by hand?

    Run cp .env.example .env and fill it in yourself (generate each secret with openssl rand -hex 32) — every setting is in the Configuration reference. Either way, never commit .env.

  8. Start Astrodock

    Bring up the stack (or add --up to the setup command above to do both at once):

    docker compose up -d

    The first run downloads and builds the images, which can take a few minutes on a small droplet. Watch progress with docker compose logs -f api, and check that everything is up with docker compose ps.

  9. Log in

    Open https://admin.apps.example.com and sign in with the ASTRODOCK_ADMIN_EMAIL / ASTRODOCK_ADMIN_PASSWORD you set. The HTTPS certificate is issued automatically on the first visit — if you see a brief error, wait a few seconds and reload (and make sure DNS has propagated).

Other beginner-friendly hosts

Prefer somewhere else? The steps are nearly identical on any provider — create an Ubuntu server, point a wildcard DNS record at it, then follow Steps 4–10 above. Good options include Hetzner Cloud (very cheap), Linode/Akamai, Vultr, and AWS Lightsail. See Your own server / any VPS for the provider-agnostic version.
