Type

Public Sans, falling back to the system font, and a mono for ids and data. Hierarchy comes from size and weight. Four weights only: 400 text, 500 navigation and meta, 600 headings, buttons and labels, 700 display numbers. Chrome text (buttons, tabs, menus) is 13px; content (inputs, options, body) is 14px.

Space and size

A 4px scale. Related things 8px apart, groups 16 to 24px, sections 32px. Controls are 30, 36 or 42px tall (40px on a phone); menu items, options and nav items are 32px. Pages are 760px (forms, reading), 1200px (most) or 1520px (big tables).

Radius and depth

Three radii and one rule for each. Avatars and identity tiles are rounded squares, never circles; only things that move along a track (switches, progress, radios, spinners) are round. Depth has three steps: card, raised (hover), pop (menus, dialogs, toasts).

Icons

Lucide, 16px, 1.8 stroke, the color of the text beside them. An icon sits next to a word; icon-only buttons are kept to universal ones and carry an accessible name. No emoji.

Motion

Motion confirms that something happened: a menu opens, a dialog arrives, a toast appears. 120ms for hover and small changes, 220ms for things entering. Nothing loops except progress. Reduced-motion settings turn it off.

Theming an app

An app loads kit.css, then its own theme.css that sets tokens. That file is the only place brand values live. Set data-theme on html to light, dark or auto.

/* app/src/theme.css */
:root { --accent: #0f6fde; --accent-hover: #0b5bb8; --accent-ink: #0a4f9e; --accent-soft: #e8f1fc; }
:root[data-theme="dark"] { --accent: #5ea2f0; --accent-ink: #9cc6f7; --accent-soft: #14253b; }
