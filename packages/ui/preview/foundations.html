Foundations

Tokens are the only thing an app changes to look like its own brand. Rules use tokens, never raw values. Switch the theme at the bottom left: every swatch below is the live token.

Color

Neutrals carry almost everything. One accent marks what can be clicked and what is selected. Success, warning and danger mean exactly that and appear with an icon and a word, never as decoration. Chart series have their own colors and never stand in for status.

Type

One plain sans-serif (Public Sans, falling back to the system font) and a mono for ids and data. Hierarchy comes from size and weight, not color. Body text is 14px in working screens; long reading text uses the prose style.

Space and layout

A 4px scale. Related things sit 8px apart, groups 16 to 24px, sections 32px. Pages have three widths: narrow (760px) for forms and reading, standard (1200px) for most pages, wide (1520px) for big tables and boards.

Shape and depth

Corners are 6px on controls, 8px on cards and 12px on dialogs. Depth has three steps: card (resting on the page), raised (hovered or floating) and pop (menus, dialogs, toasts).

Icons

Lucide, 16px, 1.8 stroke, the color of the text beside them. An icon sits next to a word; icon-only buttons are kept to universal ones (close, more, refresh, menu) and always carry a label for screen readers. No emoji.

Motion

Motion confirms that something happened: a menu opens, a dialog arrives, a toast appears. 120ms for hover and small changes, 220ms for things entering. No motion that delays reading, nothing that loops except progress. Reduced-motion settings turn it all off.

Theming an app

An app loads kit.css, then its own short file that sets tokens. That file is the only place brand values live.

/* app/src/theme.css */
:root {
  --accent: #0f6fde;
  --accent-hover: #0b5bb8;
  --accent-ink: #0a4f9e;
  --accent-soft: #e8f1fc;
}
:root[data-theme="dark"] {
  --accent: #5ea2f0;
  --accent-ink: #9cc6f7;
  --accent-soft: #14253b;
}

Set data-theme on <html> to light, dark or auto (follows the device). Dark values are chosen, never an automatic invert.
