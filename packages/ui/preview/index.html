How Astrodock apps are built

One quiet, precise system for every app on the platform. Tokens make primitives, primitives make components, components make page types, and every screen is one of the page types.

Principles

Content leadsOne quiet frame; the page is a single white panel. Titles, data and the main action come first.
One way to do each thingOne button, one select, one list, one checkbox. A screen never invents a control.
Fewer boxesStructure from type, space and hairlines. Cards only for things that are objects.
Color means somethingThe accent is the primary action, focus and checked. Green, amber and red mean what they say.
Always a way backA back link names the parent; the URL keeps the tab, view and filters.
Every state designedLoading, empty, no matches, error, no access, running: each has a set look and words.
