Your own little app platform.

Astrodock installs once on a machine you control — a cheap server, or your laptop — and then hosts the small apps you build on it, with user login, a database, file storage and HTTPS included. No accounts to sign up for. No cloud bill.

Get started What is Astrodock?
$ curl -fsSL https://raw.githubusercontent.com/astrodock/astrodock/main/scripts/install.sh | sh

On a fresh Linux server. It fetches the compose file, generates every secret, pulls the images and starts the stack — then you finish in the browser.

Everything a small app needs, already wired up

The parts you would otherwise assemble from four different vendors, running on one box and talking to each other out of the tin.

Sign-in you don't write

Your users get accounts, passkeys and two-factor without you building any of it. Your app never sees a password — it receives a one-time code and trades it server-side.

A database and storage per app

Each app can get its own Postgres database and its own file storage, created for it and handed to it as a connection string. Or point it at your own — that choice is config.

HTTPS that just happens

Real certificates, renewed on their own. Bring your own domain and Astrodock shows you the exact DNS records, checks them for you, and turns on encryption when they land.

Push to deploy

Connect a repository and every push to your branch rebuilds and goes live. Or push straight from your machine with the CLI. Every build is kept, with its full log.

Built to be handed to an agent

A scoped API token and a small CLI, so you can point Claude Code — or any agent — at your platform and let it create, configure and deploy apps for you.

You can see what it's doing

Logs, deploy history, sign-in records, health checks and backups — in one dashboard, on your machine. Nothing is phoned home, because there is nowhere to phone.

From nothing to a live app

Three steps, and the middle one is a browser form.

1

Install it

One command on a fresh Linux box. It pulls the images and starts everything — there is no source tree to build and no config file to hand-edit.

2

Finish in the browser

Open the server's address. The wizard makes your admin account, takes your domain, shows you the DNS record to add, checks it, and switches on HTTPS.

3

Deploy something

Point it at a repository, or run astrodock deploy. Your app comes up on its own address with its database, storage and login already attached.

What "self-hosted" actually means here

Some projects call themselves self-hostable and still expect you to bring a managed database, an S3 bucket and an auth provider. This one doesn't.

  • ✓ The database ships with it. Postgres runs in the stack. You do not sign up for anything to store data.
  • ✓ Object storage ships with it. An S3-compatible store runs alongside, so file uploads work on day one.
  • ✓ Auth is part of the platform. Not a SaaS integration, not a library you wire up — a sign-in page the platform serves for your apps.
  • ✓ Your data stays on your box. Sign-ins, logs, uploads, backups. The only request Astrodock makes on its own is an optional check for new releases.
  • ✓ It's MIT licensed. Read it, fork it, run it forever. No seat count, no tier that unlocks the useful part.

Give it a machine and ten minutes

A small server — around $12 a month — runs the whole platform and the apps on it. The docs take you from a blank box to a deployed app with a real address.
